# AMR Genomic Surveillance

A mid-term project analyzing antimicrobial resistance (AMR) using genomic data, exploring how sequence-level and molecular features relate to resistance patterns across bacterial isolates.

## 🎯 Project Overview

Antimicrobial resistance (AMR) is a growing global health threat, and genomic surveillance — tracking resistance genes and mutations directly from sequence data — offers a faster, more scalable alternative to traditional lab-based susceptibility testing. This project explores AMR through a genomics lens, applying bioinformatics and data analysis techniques to identify resistance-associated patterns in the available dataset.
